# 🧠 ReLearn
### Adaptive Learning Through Misconception-Aware AI

<p align="center">

**Don't just tell students they're wrong. Understand why.**

ReLearn is an AI-powered adaptive learning environment that identifies the **underlying misconception behind a learner's response**, provides a **targeted intervention**, and reassesses the learner to determine whether the misconception has actually been resolved.

</p>
